# Changelog

Each release's notes go under a `## <version>` heading; the release workflow shows them on the GitHub Release and in
Jellyfin's plugin catalogue.

## 0.1.0

First public release, for Jellyfin 12.

- A new web app at the server address (Jellyfin's own app moves to `/old`), or alongside it at `/seedy`.
- Home screen that learns from each profile, with featured titles and their trailers.
- Search as you type, with Seerr results under the library's.
- Requests through Seerr, My requests.
- Live TV: On now, guide, channels, recordings, series rules and a live player.
- Player with skip intro/recap/credits, chapters, seek previews, styled subtitles, Up next and Watch together.
- Play log, viewing history and Top 10.
- Personal settings and a complete admin dashboard.
- English and French.
